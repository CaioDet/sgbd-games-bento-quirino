# Banco de Dados - Ensino Médio Técnico

Repositório oficial para disponibilização de materiais, scripts SQL, guias práticos e avaliações da disciplina de Banco de Dados voltada para os cursos técnicos.

## Sobre a Disciplina

Este repositório tem como objetivo centralizar os códigos, roteiros de aulas práticas e exercícios desenvolvidos ao longo do período letivo, auxiliando no aprendizado de modelagem de dados, DDL, restrições (*constraints*) e validação física utilizando SGBDs como o SQLite.

## Como Utilizar

1. Acesse os arquivos na pasta correspondente à aula ou atividade desejada.
2. Utilize o ambiente online indicado para a execução dos comandos DDL e testes de restrições (`NOT NULL`, `UNIQUE`, `CHECK`, `DEFAULT`, `FOREIGN KEY`).
3. Realize o upload dos arquivos `.sql` desenvolvidos conforme as orientações de entrega de cada projeto.

## Diretrizes de Uso

Os materiais aqui presentes são de uso exclusivo para o apoio pedagógico das turmas do ensino técnico. O desenvolvimento das atividades deve seguir rigorosamente as regras de modelagem e restrições exigidas em cada enunciado.
